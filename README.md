# Simple Interest Calculator

## Project Description

The Simple Interest Calculator calculates the simple interest and total amount based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Total Amount = Principal + Simple Interest

## Inputs

- Principal: The initial amount of money.
- Rate: The annual interest rate in percentage.
- Time: The period of time in years.

## Example

If the principal is $1000, the annual interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = $100

Total Amount = $1000 + $100

Total Amount = $1100

## Purpose

This project demonstrates how simple interest can be calculated using basic programming concepts.
